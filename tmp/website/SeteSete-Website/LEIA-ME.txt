Como publicar
  1. Instalar Node.js 22.
  2. Na pasta deste ZIP:
       npm install
       npm run build
  3. O projecto está preparado para Vercel (vite + TanStack Start).
     Basta ligar o repositório ou fazer upload desta pasta.

  Em desenvolvimento local:
       npm run dev
     o site abre na porta 8080.
